Import MiSiS Attendance
MiSiS is the official record. Choose one or more Attendance Referral Report PDFs (one per student, or several students in one file). You'll see how each day compares with the check-ins before anything is saved.
Saving writes each day's MiSiS status to the AttendanceFinal tab. Importing the same dates again updates them; it never creates duplicates. Days MiSiS marks absent are removed from check-in streaks.
Import FileMaker Points
Choose the FileMaker Point Sheet PDF (one student per page). Each class is matched to that student's course tab, and you'll see every cell that would change before anything is saved. Prev and the weekly points are written; grades are not touched, and a blank in the PDF never erases a number in the sheet.
Only matched classes are saved. Every changed number is recorded in the AuditLog with its old value. Unmatched classes are skipped - add a row to the PointsClassMap tab (FileMaker class name | words in the course title) and run the import again to pick them up.
Honor Roll & Intervention
Weekly points are added up across all of a student's classes (Prev not included). 30+ in a week = Honor Roll; under 30 = Probation. Each 5-week block needs 150+ points (30 per week the student was enrolled); under that = after-school intervention.
Advisory (Period H)
Choose the MiSiS Student Schedule Summary Report (.xlsx, with the Student ID and Period H columns). Each advisor gets an Advisory course tab, so Period H shows on every student's schedule. MiSiS decides who is in each advisory: students who moved or left are marked removed (any points kept). Upload it again whenever advisories change.
Upload Transcripts
Choose the MiSiS Transcript Report (.xlsx, one sheet per student, named by Student ID). Every term is checked against the report's own credit totals. Review the courses that need a category, then save. Uploading a student again replaces their transcript.
