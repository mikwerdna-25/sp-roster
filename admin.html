Import MiSiS Attendance
MiSiS is the official record. Choose one or more Attendance Referral Report PDFs (one per student, or several students in one file). You'll see how each day compares with the check-ins before anything is saved.
Saving writes each day's MiSiS status to the AttendanceFinal tab. Importing the same dates again updates them; it never creates duplicates. Days MiSiS marks absent are removed from check-in streaks.
Import FileMaker Points
Choose the FileMaker Point Sheet PDF (one student per page). Each class is matched to that student's course tab, and you'll see every cell that would change before anything is saved. Prev and the weekly points are written, and a blank in the PDF never erases a number in the sheet. A class that isn't on the student's MiSiS schedule is still listed, with its points (and grade if completed), under a flagged "Not on MiSiS" class that has no teacher. College & Career rows are set to match the PDF exactly for the weeks it covers.
Matched classes and the flagged "Not on MiSiS" classes are saved. Once a student's schedule is fixed, add them to the right section in Manage Courses and import again. Every changed number is recorded in the AuditLog with its old value. Unmatched classes are skipped - add a row to the PointsClassMap tab (FileMaker class name | words in the course title) and run the import again to pick them up.
Honor Roll & Intervention
Weekly points are added up across all of a student's classes (Prev not included). 30+ in a week = Honor Roll; 20–29 = good standing; under 20 = Probation. Each 5-week block needs 100+ points (20 per week the student was enrolled); under that = after-school intervention.

Advisory (Period H)
Choose the MiSiS Student Schedule Summary Report (.xlsx, with the Student ID and Period H columns). Each advisor gets an Advisory points class, so Period H shows on every student's schedule. Advisory has no 75-point completion: its points go to the student's College & Career class. MiSiS decides who is in each advisory: students who moved or left are marked removed (any points kept). Upload it again whenever advisories change.
Upload Transcripts
Choose a MiSiS High School Transcript CSV Report (.xlsx, one sheet, many students — checked against each student's Total Credits) or the older Transcript Report (.xlsx, one sheet per student, named by Student ID). Every term is checked against the report's own credit totals. Review the courses that need a category, then save. Uploading a student again replaces their transcript.

Hall pass links

Change my code
Your code is yours alone — everything you look up or change is logged under your name. Use at least 6 characters, no spaces. After you change it, the old code stops working.
Student List
Every student the system knows, from the StudentList tab. Tap a student to fix a name (preferred names too), grad year, other names they go by, or notes. A name change is also made in their class rows and the check-in roster. The Student ID can't be changed here. To take a student off the active list, use Archive a Student; to add one, use Add a New Student.
Double Blocks
A student scheduled in the same course in two or more periods. The periods are linked as one course: points entered in either period are copied to the other, one grade completes the course in every period, and weekly Honor Roll, credits and the graduation check count it once. Opening this page also fills in any week that was entered in only one period.
Add a New Student
This is the only place a new student is created. To put a student who is already here into a class, use the course page's student list or type their existing Student ID below. Use the student's name and Student ID exactly as in MiSiS. They are added to the school list (teachers, counselors, imports, transcripts, graduation check) and to the check-in roster. Then check off their classes — including their advisory — and save. You can come back later to add more classes for the same Student ID.
Master Schedule — students per teacher and period
Tap a number for that roster; tap a teacher for their whole day. Empty boxes show what the master schedule plans for periods 1–5. Yellow = at the class size, red = over it.
